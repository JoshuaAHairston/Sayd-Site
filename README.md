# Our Timeline

A website holding the photos Sadie and I have taken with each other over the years.

## What's inside

- **A landing page** with floating photos to start the journey.
- **A timeline of each year,** laid out month by month.
- **A closer look at each month,** where you can move through the days and see the photos from each one.

## Running it

```bash
npm install
npm run dev
```
